# Smart Trader Hub - Mobile App (Flutter)

This directory is intended for the Flutter mobile application (Android/iOS).

## Getting Started

1.  **Install Flutter:** Follow the instructions on the [official Flutter website](https://flutter.dev/docs/get-started/install).
2.  **Navigate to this directory:** `cd mobile_app`
3.  **Create the Flutter project (if not already done by a developer manually):**
    ```bash
    # If this directory is empty or only contains this README, run:
    # flutter create .
    # Or, to create in a subdirectory (e.g., 'app_code'):
    # flutter create app_code
    ```
    If the project is already set up, you can skip this step.
4.  **Run the app:**
    ```bash
    flutter run
    ```

## Project Structure (Typical)

A typical Flutter project includes:

-   `lib/`: Contains most of the Dart code.
    -   `main.dart`: The entry point of the application.
-   `pubspec.yaml`: Manages project dependencies and metadata.
-   `android/`: Android-specific project files.
-   `ios/`: iOS-specific project files.
-   `test/`: For unit and widget tests.
